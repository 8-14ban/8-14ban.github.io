01 / 简介

我们是谁

About the Class

星耀

一群把日子过成故事的人

十四

五十个性格各异的少年，在同一个秋天走进了同一间教室。从开学连名字都叫不全，到现在一个眼神就知道对方想干什么。

班徽上是「星耀」两个字，底下写着「自信自强 · 闪闪发光」。每个人都能被看见，这就是我们想要的样子。
